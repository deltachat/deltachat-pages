---

Delta Chat حالا از **گروه‌های ad-hoc** پشتیبانی می‌کند - به‌طور خلاصه، گروه‌ها می‌توانند توسط هر کلاینت غیر Delta ایجاد شوند و بر اساس فهرست گیرندگان ثبت می‌شوند.
به‌جز این، «گروه‌های ad-hoc» مثل گروه‌های معمولی Delta کار می‌کنند. برای جزئیات و بحث بیشتر [issue #69](https://github.com/deltachat/deltachat-core/issues/69#issuecomment-370247669) را ببینید.

تغییرات بیشتر:

* امکان **ایجاد گروه از طریق درخواست‌های تماس**
* همیشه **نمایش زمان _ارسال_** در فهرست چت؛ خود فهرست بر اساس زمان _دریافت_ مرتب می‌شود و «Message info» حالا هر دو زمان را نشان می‌دهد
* **نشان‌دادن بخش‌های حذف‌شده** ایمیل‌ها با «[...]»
* **برجسته‌کردن موضوع** در «Message info»

برای فهرست کامل تغییرات و لینک‌های دانلود، [downloads](download) را ببینید. مثل همیشه، نسخه فوراً روی Github و ظرف چند روز روی F-Droid در دسترس است.

این نسخه به **مجوز دسترسی به دوربین** نیاز دارد. این برای گزینه‌های آینده اسکن QR code لازم است که همین الان در این نسخه قابل تست است؛ commit [74ffbf4](https://github.com/deltachat/deltachat-android/commit/74ffbf48befbb0416337673d73d9f2482728cac6) را ببینید.


## چه خبرهای دیگری؟

- حالا یک **لیست پستی** داریم؛ می‌توانید [اینجا عضو شوید](https://lists.codespeak.net/postorius/lists/delta.codespeak.net/)

- همچنین از **کانال IRC #deltachat** روی freenode استفاده می‌کنیم - اگر کلاینت IRC ندارید، می‌توانید از طریق [KiwiIRC]({% include webirc-url %}) یا [qwebirc](https://webchat.freenode.net/?uio=MTE9MjA16a&channels=%23deltachat) هم دسترسی داشته باشید [ویرایش: KiwiIRC اضافه شد]
